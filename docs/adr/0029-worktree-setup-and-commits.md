# Branch cutting, worktree setup, Run environment and commits

A Phase branch is cut from `<remote>/<baseBranch>` after a fetch. If the remote is unreachable, the Phase start retries every 5 minutes with a visible reason. It never silently falls back to the local branch. A Task's worktree is created when it first leaves `ready`, from the Phase branch tip. The configured setup command runs as a script Run after creation, and again after a merge brings in lockfile changes. Its failures are infra failures, and exhausting the budget blocks the Task with `setup-failed`. Every Run gets `SEGNO=1`, `SEGNO_TASK_ID`, `SEGNO_RUN_ID` and `SEGNO_SLOT`. The test command runs through the shell at the worktree root and passes only on exit code 0. After each Coder Run, the Engine commits anything left uncommitted, so tests and review always see a clean HEAD. Commits use the developer's git identity with a `Segno-Task` trailer.
